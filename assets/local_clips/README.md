# Your own footage (optional)

Put `.mp4` files that **you own or have permission to use** in this folder and
set `sources.local: true` in `config.yaml`.

The filename becomes the searchable text, so name files descriptively:

```
cozy-living-room-curtains.mp4
modern-kitchen-counter.mp4
bedroom-warm-lamp-evening.mp4
```

Requirements: landscape, at least 1280x720, at least about 5 seconds long.

This is **not** a place for other people's videos downloaded from social media.
The automated pipeline only uses licensed stock footage from Pexels and Pixabay.
